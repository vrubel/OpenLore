# Tasks — pdlc-3402-process-leaks (vrubel/openlore)

Порядок: сначала проверка, которая падает на коде тега `v2.1.3-ru20` и проходит на новом (процесс-утечка после
сценария жив, после правки мёртв; рядом живёт чужой процесс-свидетель, и он выживает), затем правка. Что не
воспроизводится на Linux-раннере (macOS, Windows), отмечается явно; живое подтверждение снимает владелец.

## 1. PDLC-3414 — консолидация решений (PDLC-3407 п. 3, F-OPS-021.R3)

- [ ] 1.1 Проверка: после `record_decision` сервер закрыт каждым из способов ядра — SIGTERM и по сроку SIGKILL номеру
      процесса, SIGKILL номеру процесса, SIGTERM и SIGKILL каждому номеру дерева, SIGKILL группе — и процесс
      `openlore decisions --consolidate` жив хотя бы при одном из них.
- [ ] 1.2 Правка: консолидация без `detached: true` и `unref()`, в группе сервера MCP, либо гашение при закрытии
      сервера (`src/core/services/mcp-handlers/decisions.ts:28-53`), так что она гибнет при каждом способе из 1.1.

## 2. PDLC-3414 — выход сервера MCP по закрытию stdin под ключом (F-OPS-021.R3)

- [ ] 2.1 Проверка режима `--http`: сервер с ключом `--exit-on-stdin-close` отвечает, пока труба stdin открыта, и
      выходит после её закрытия. На коде тега ключ не принят, и проверка красная.
- [ ] 2.2 Проверка режима stdio: сервер с ключом `--exit-on-stdin-close` отвечает клиенту и выходит после закрытия
      stdin. На коде тега ключ не принят, и проверка красная.
- [ ] 2.3 Ограда: сервер `openlore mcp --http` без ключа со stdin из `/dev/null` жив и отвечает — и на коде тега, и на
      новом.
- [ ] 2.4 Правка: ключ `--exit-on-stdin-close` команды `openlore mcp`; с ключом — выход по закрытию stdin в режимах stdio
      и `--http`, без ключа — прежнее поведение.

## 3. Тег и пин

- [ ] 3.1 Тег форка — только по отдельному слову владельца, записанному в PDLC-3414. Пин установщика
      (`scripts/forks.lst` pdlc-core) двигается тем же словом вместе с запуском `openlore mcp --http` ядром с ключом
      `--exit-on-stdin-close` и трубой stdin (задача 11 локального изменения ядра).
